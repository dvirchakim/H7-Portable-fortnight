FC Carrier R0.3

A 68 × 40 mm flight-controller carrier for Arduino® Portenta H7. It plugs onto the module's two high-density connectors and turns it into an ArduPilot-class autopilot with Pixhawk-standard ports, microSD logging and DroneCAN.

Status fab-ready, not yet builtChecks DRC · ERC · DFM · EMI · socket matchSource KiCad 7, generated from one Python netlist

Verdict

The hardware is sound and ready for a first prototype run. The review found five functional problems that would have shown up only on the bench or in flight. All five are fixed in R0.3: the ADC reference, a shared ESC-telemetry UART, an LED output on a timer without DMA, fragile analog sense pads, and too little buck output capacitance.

The real gap is firmware. No ArduPilot, PX4 or Betaflight build exists for the Portenta's STM32H747. ArduPilot already runs the nearly identical STM32H757, so a port is realistic: about 8–12 person-weeks to a flying prototype.

Recommended path: build five boards, port ArduPilot, fly them, then approach Arduino as a Technical Partner with flight logs, a family-compatibility matrix and volume pricing.

How the review was run

Six tracks worked in parallel, each with a written brief and sourced findings. The layout lead then fixed the board and re-ran every check.

Hardware integration

How a carrier must treat the Portenta's power, reference and boot pins; family compatibility with H7 Lite, C33 and X8.

Firmware and MCU pins

ArduPilot, PX4, Betaflight and INAV support; timer, DMA and UART capability of every pin used, from ArduPilot's STM32H757 tables.

Block-by-block check against the TI, TDK, TE and ST datasheets.

Portenta family compatibility

Arduino will ask which modules the carrier supports. The answer, pin by pin:

ModuleVerdictNotes
Portenta H7TargetAll functions as designed.
Portenta H7 LiteYesSame pinout; no Wi-Fi or Bluetooth, which a flight controller does not need.
Portenta C33PartlySame pins for UARTs, I2C, CAN, SD and SPI. The C33 Arduino core lacks PWM on some outputs and UART flow control. J2-71 is an output there, so build without the reference (U7).
Portenta X8Not as a flight controllerUART2 carries the Linux console, SWD reaches the i.MX, and real-time I/O goes through the Linux-to-STM32 bridge. It can draw 0.8 A on VIN.

Firmware plan

ArduPilot is the realistic target. A board definition for this carrier needs:

  • Clock: the Portenta's 25 MHz oscillator in HSE-bypass mode, enabled by PH1 before clock start-up.
  • Supply mode: "SMPS 1.8 V supplies LDO", a small addition to ArduPilot's power-mode options.
  • Bootloader and PMIC: keep Arduino's MCUboot (application at 0x08040000), which already configures the PF1550 PMIC. About 1.4 MB of flash remains for the application.
  • USB: the USB-C port uses a ULPI high-speed PHY that ArduPilot does not support yet. Start with MAVLink over the telemetry UART.
  • Pins: the IMU bus is the MCU's SPI2; ESC telemetry is UART7 RX; TELEM1 flow control runs on GPIOs; the M4 core stays halted.

Effort: 8–12 person-weeks to a flying prototype with logging, for one engineer who knows ArduPilot. Main risks: a wrong supply mode leaves the MCU unbootable until recovered over SWD; the flash budget with MCUboot; USB high-speed support.

Where it fits

Between FPV boards and the Pixhawk class: 7-inch and larger long-range, research and teaching aircraft. It cannot win on price against $85–130 FPV boards.

What only it offers

A swappable Arduino module and the Arduino toolchain, with the M4 core free for the user's own code beside the autopilot. Arduino has no flight-control product today.

Gaps against the market

Single unheated IMU, no 9–12 V video regulator, four UARTs, six PWM outputs, no OSD chip. All are in the R0.4 plan or acceptable for digital video.

Working with Arduino

Route in

Arduino's Technical Partner track, through the Arduino Pro contact form. Ask for design validation, a store listing and blog or docs coverage before any co-branding. Precedent: ROBOTIS's DYNAMIXEL shield was blogged and is sold by Arduino.

Name and licence

Own brand, phrased "<Brand> flight-controller carrier for Arduino® Portenta H7", with the wording approved in writing. No Arduino marks on the board. Open hardware under CERN-OHL-W.

What to bring

A flying prototype with logs; vibration, brown-out and thermal data; the compatibility matrix in Arduino's datasheet style; an Arduino library with examples; 1k / 5k pricing; a CE / FCC plan and a support model.

Next steps

  1. Order five boards from JLCPCB, with the Hirose sockets consigned; check U6, U7 and J11 in the placement preview.
  2. Bring-up on the bench: rails, SWD, IMU and barometer, microSD, CAN, buck load step at 12 V and 25 V.
  3. Write the ArduPilot board definition and fly on a 7-inch frame with logging.
  4. Fold the findings into R0.4 with the items above.
  5. Contact Arduino Pro with the flight data and this review.
